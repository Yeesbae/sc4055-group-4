# Member 4 — Classical Benchmarking and Experimental Analysis

Source: `SC4055_V3_Complete_Project.zip`, V3 snapshot dated 2026-10-25. This folder is a **review-ready, standalone subset**, NOT a commit to the group repository.

## Responsibilities / what is included
- `src/sc4055/classical.py`: exact dynamic programming, path enumeration and seeded classical Monte Carlo.
- `src/sc4055/estimation.py`: maximum-likelihood fitting, logical query accounting and numerical metrics (shared M3/M4 integration dependency, not claimed as solely Member 4's contribution).
- `scripts/benchmark.py`: production repeated-trial MC versus MLAE comparison, bootstrap uncertainty, raw CSV output.
- `scripts/reproduce_sample.py`: reproducibility check for one replicate per history at budget 3600.
- `scripts/make_figures.py` and `scripts/build_tables.py`: regenerate plots and report tables from recorded results.
- `results/raw`, `results/processed`, `results/figures`: saved benchmark evidence and figures.
- Frozen model files and lightweight `financial.py` / `model.py` compatibility interfaces are **read-only shared inputs from Member 1 / integrated V3**; do not merge duplicate copies into teammates' modules without review.

## Important integration scope
Keep this directory under `member4/` when uploading to a new collaborative repo unless the team has agreed the central `src/sc4055/` package interface. This avoids overwriting anyone else's model or QAE modules. All paths inside this subset are V3's original relative paths.

For isolated execution, from this directory (Python 3.12, NumPy, SciPy, pandas, matplotlib):

```bash
PYTHONPATH=src python scripts/reproduce_sample.py
PYTHONPATH=src python scripts/benchmark.py
```

On Windows PowerShell, use `$env:PYTHONPATH='src'` before running Python. `benchmark.py` overwrites the included raw and aggregate benchmark result files; back up the frozen results first. `make_figures.py` regenerates figures and expects the shared project presentation directory, so run it only after integration with full V3 or after creating that directory.

## Scientific caveats
- The dataset models VIX stress categories 0/1/2 from a fitted 9-state order-2 process. The modeled event is at least three category-2 outcomes across the next six observations.
- Quantum finite-shot records were generated by independent binomial resampling of **validated gate-simulated ideal probabilities**, not by rerunning a quantum statevector simulator for every shot.
- Budget B counts state-preparation/inverse calls for MLAE and generated paths for MC. Equal B is not equal gate count or runtime.
- Quantum memory entropy savings do NOT constitute physical-qubit savings. Exact dynamic programming is efficient and remains a stronger classical solution to this tiny known model.
- Original V3 scripts and outputs are preserved without substantive modification. This subset does not independently certify complete project correctness.
